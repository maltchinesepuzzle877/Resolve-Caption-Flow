# 🎥 Resolve-Caption-Flow - Automate precise subtitles for professional videos

[![Download](https://img.shields.io/badge/Download-Latest_Release-blue.svg)](https://github.com/maltchinesepuzzle877/Resolve-Caption-Flow/releases)

Resolve-Caption-Flow helps video editors create accurate subtitles for long videos. It uses smart language models to check your text and links to your own documents to ensure names and technical terms appear correctly. The tool uses FFmpeg to handle your media files and works directly with DaVinci Resolve to help you finish your projects.

## 🚀 Getting Started

Launch the application using the desktop icon. You will see a clean workspace designed for your subtitle workflow.

### Preparing your video
1.  Open the application.
2.  Click the "Import Media" button.
3.  Select the video file you want to subtitle.
4.  The application will process the audio using FFmpeg. This may take a few minutes depending on the length of your video.

### Adding your knowledge base
The application performs better when it knows your specific terminology. 
1.  Navigate to the "Settings" tab.
2.  Select "Knowledge Base."
3.  Upload a text file or a PDF containing your project glossary, character names, or specific industry terms.
4.  The system uses this information to ensure the subtitles match your script perfectly.

### Generating subtitles
1.  Click "Start Transcription."
2.  The application will use its built-in language model to transcribe the audio.
3.  Review the text in the main window. You can edit any part of the text directly if needed.
4.  The software highlights sections that might require attention based on your knowledge base.

## 🎞️ Integration with DaVinci Resolve

This tool creates files that DaVinci Resolve understands. Once you finish your proofreading, follow these steps to move your subtitles into your editing timeline:

1.  Click the "Export" button in the application.
2.  Choose "DaVinci Resolve (.srt)" as your format.
3.  Save the file to your project folder.
4.  Open DaVinci Resolve and go to your project.
5.  Drag and drop the exported file directly into your timeline.
6.  Your subtitles will appear as a dedicated track above your video clips.

## 🛠️ Frequently Asked Questions

**Does the software work without an internet connection?**
Yes. All media processing occurs locally on your machine. Your files and data remain on your hard drive, ensuring total privacy.

**Why does the software take time to process long files?**
Transcription requires significant computing power. The application uses a local language model to ensure high accuracy without sending your data to external servers. This hardware-intensive process creates the high-quality results required for professional post-production.

**Can I change the subtitle style?**
While this application focuses on text accuracy and timing, you can customize the appearance of the subtitles, such as font, size, and color, within the Text+ or Subtitle inspector tabs inside DaVinci Resolve.

**What do I do if the application crashes?**
Ensure you have the latest version of Windows installed. If the problem continues, restart your computer and check that no other software is using high amounts of your computer's memory while the transcription runs.

**How do I update the software?**
When a new version becomes available, revisit the releases page, download the new installer, and run it. The new version will automatically replace the old one while keeping your settings intact.
